Heavy ad test tool

Runs a panel inside any page. It finds ad iframes, installs the heavy ad sample script into the one you pick, makes that frame burn CPU until Chrome removes it, and reports what the script did.

Option 1 (most reliable): paste into DevTools

  1. Open the page you want to test in desktop Chrome and wait for ads to load. Turn device emulation off.
  2. Press F12, open the Console.
  3. Click the button below, then paste into the Console and press Enter.

Option 2: bookmarklet

Drag this link to your bookmarks bar, then click it on any page:

Heavy ad test

Some sites block bookmarklets. If nothing appears, use Option 1.

Using the panel

  1. Pick an ad frame from the list. Only same-origin frames (for example Google ad frames named google_ads_iframe_...) can be used. Cross-origin frames are listed greyed out.
  2. Leave Capture only selected to send nothing, or choose Send a real beacon to send exactly one to the pixel URL you set.
  3. Click Start test. Keep the tab in front and do not click inside the ad.
  4. Wait about 20 s. The panel shows PASS, FAIL or INFO, and a timeline. Copy report copies it as text.

See README.md for what each verdict means.
